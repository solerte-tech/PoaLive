# Design system
**Conceito:** a hora dourada no Guaíba. Calma e segurança (azul-lago e verde-água) com o calor do pôr do sol como destaque de ação.

| Token | Hex | Uso |
|---|---|---|
| Lago | #0E3B4F | fundo escuro, navegação |
| Água | #1C7C86 | primário, rotas, confiança |
| Névoa | #EAF3F1 | superfícies claras |
| Pôr do sol | #FF8A3D | eventos, destaque, ação |
| Magenta | #E0457B | evento ao vivo agora |
| Folha | #4FB286 | local tranquilo |

**Tipografia:** Fraunces (títulos) + DM Sans (interface).
**Lotação:** verde = tranquilo, âmbar = moderado, magenta = lotado.
**Navegação inferior:** Mapa, Agora, Roteiros, Salvos, Perfil.
**Acessibilidade:** contraste AA, alvos de toque de 44 px, respeita "reduzir movimento".
